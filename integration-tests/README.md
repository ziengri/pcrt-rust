# Интеграционные тесты

Здесь будут сценарии, которые нельзя проверить unit-тестом одного crate:

- отключение питания между записью session manifest и atomic rename;
- restart после claim до подтверждения API;
- сеть отсутствует, затем восстанавливается без новой сессии;
- конкурентная работа result queue и SQLite lock;
- `SIGTERM` во время записи ffmpeg и inference;
- совместимость Rust door gateway с Python recorder.

Тесты добавляются вместе с соответствующей инфраструктурной библиотекой.
